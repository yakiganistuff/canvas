# קנבס המנופים · STUFF

כלי עבודה לסדנאות: כל יוזמה מקבלת קנבס, כל קוביה נערכת ונשמרת בנפרד, ומאמן AI מאתגר, שואל ומציע ניסוח.

## הרשאות
- **אדמין**: רואה ומנהל את כל הארגונים, המשתמשים והפרויקטים.
- **מנהלת**: רואה את כל הפרויקטים של הארגון שלה ועורכת בהם. לא מנהלת משתמשים או פרויקטים.
- **משתמשת**: רואה רק את הפרויקטים שהיא משויכת אליהם.

כל הבדיקות נעשות בשרת. סיסמאות נשמרות כ־hash (scrypt), וההתחברות נשמרת בעוגייה חתומה ל־14 יום.

## העלאה ל־Vercel
1. ב־Vercel: **Add New → Project**, ובוחרים את הריפו הזה. ההגדרות נקראות מ־`vercel.json`, אין build.
2. בלשונית **Storage** של הפרויקט: מחברים **Upstash for Redis** (Marketplace). המשתנים `KV_REST_API_URL` ו־`KV_REST_API_TOKEN` (או `UPSTASH_REDIS_REST_URL` / `UPSTASH_REDIS_REST_TOKEN`) נוספים לבד.
3. ב־**Settings → Environment Variables** מוסיפים:

| משתנה | מה זה |
|---|---|
| `ANTHROPIC_API_KEY` | מפתח API של Anthropic, בשביל המאמן |
| `SESSION_SECRET` | (רשות) אם לא מוגדר, נוצר אוטומטית ונשמר במסד |
| `ADMIN_USERNAME` | שם המשתמש של האדמין, למשל `yaki` |
| `ADMIN_PASSWORD` | הסיסמה לכניסה הראשונה של האדמין |
| `ADMIN_NAME` | (רשות) שם לתצוגה, למשל `יקי` |
| `COACH_MODEL` | (רשות) ברירת מחדל: `claude-sonnet-5-5` |

4. **Redeploy**. נכנסים עם `ADMIN_USERNAME` ו־`ADMIN_PASSWORD`, והחשבון נוצר בכניסה הראשונה. משם יוצרים ארגון, משתמשים ופרויקטים בחלק "ניהול".

## משתמשים וסיסמאות
- שם המשתמש הוא כתובת המייל. מוסיפים אחד־אחד או בייבוא רשימה (מייל, שם לתצוגה), וכולם נוצרים כמשתמשים רגילים.
- הסיסמאות נוצרות אוטומטית (למשל `Hk7m-Q3tz-9Rwp`) ונשמרות רק כ־hash.
- "שליחת סיסמה" יוצר סיסמה חדשה ופותח מייל מוכן בתוכנת המייל במחשב. "שליחה לבא בתור" עובר על מי שעוד לא קיבל.
- שליחה מחדש מחליפה את הסיסמה הקודמת.
- את התפקיד (משתמשת, מנהלת, אדמין) והארגון משנים מהתפריט שבשורת המשתמש.

## הקשר למאמן
בלשונית "ארגונים" אפשר לכתוב לכל ארגון הקשר: שם האסטרטגיה, רשימת היוזמות, נתונים מהאבחון. המאמן מקבל את זה בכל שאלה, והמשתתפות לא רואות את זה.

## מבנה
- `public/`: הממשק (HTML, CSS, JS בלי build)
- `api/`: פונקציות Vercel: `login`, `logout`, `me`, `projects`, `project`, `cell`, `admin`, `coach`
- נתונים ב־Redis: `user:<id>`, `org:<id>`, `project:<id>`, `cells:<project>` (hash לפי קוביה)
